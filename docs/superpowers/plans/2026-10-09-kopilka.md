# Копилка — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iOS-приложение, которое импортирует выписку Halyk из PDF, раскладывает траты по категориям без дублей и показывает лимиты и «можно потратить до зарплаты».

**Architecture:** Вся бизнес-логика — в локальном Swift-пакете `KopilkaCore` (модели SwiftData, разбор выписки, импорт, правила, калькуляторы), тестируется командой `swift test` на Mac без симулятора. Приложение `Kopilka` (SwiftUI) — только экраны, сторы и App Intents. Сторы создаются в корне приложения и передаются вниз через `.environment`.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, PDFKit, Swift Charts, App Intents, Swift Testing (`import Testing`). iOS 17+, macOS 14+ (для тестов пакета). Xcode 27.

**Spec:** `docs/superpowers/specs/2026-10-09-kopilka-design.md` (ниже — «спека §N»).

## Global Constraints

- Стиль кода — скилл `north:code-style` + `references/swift.md`, обязателен для каждой задачи:
  - функция получает всё через параметры, никаких `.shared` и скрытых сторов внутри функций;
  - одна функция — одно действие, имя с глагола (`get/load/find`, `save/update/add`, `make/calculate/format`, `show/open`);
  - булевы `is/has/can/should`, единицы в именах (`amountTenge`, `windowDays`);
  - числа-пороги литералом в месте вызова, смысл — в имени параметра (`makeTransferRule(..., windowDaysAfterSalary: 3)`);
  - `guard` в начале, без лесенок `if/else`;
  - «не нашёл» → `nil`/пусто, сбой → `throw` и обработка в корне приложения, никаких `try?` без обработки;
  - лямбды с явным аргументом `{ entry in ... }`, никаких `$0`;
  - комментарии на русском и только «почему»;
  - папки по типам.
- Деньги — только `Decimal`, валюта KZT. Никаких `Double` для сумм.
- Даты операций — `CalendarDay` (год, месяц, день), без часовых поясов. Время нужно только для Apple Pay и SMS (`Date`).
- Описание из выписки сравнивается без пробелов и без учёта регистра (спека §2).
- Никаких App Groups и iCloud: всё должно работать на бесплатном Apple ID (спека §12).
- Реальная выписка `halyk-2026.pdf` лежит в `Packages/KopilkaCore/Tests/KopilkaCoreTests/Fixtures/` и **в `.gitignore`**.
- Тексты интерфейса на русском, с заглавной только первое слово.

## Review Focus

1. **Выписка с операциями «в обработке»**: строка с датой обработки позже даты формирования. Ожидание: импорт не падает, при следующем импорте строка не задваивается (дата обработки в ключ не входит). Тест — задача 3.
2. **Описание продавца переносится на следующую страницу PDF**: строка продолжения без даты в начале новой страницы. Ожидание: продолжение приклеивается к последней строке предыдущей страницы. Тест — задача 2.
3. **Аванс пришёл не 15-го, а 13-го или 17-го**: ожидание — граница периода по факту поступления, а «7 дней после аванса» для рассрочки считается от факта. Тест — задача 6.
4. **Выписка другого счёта или не Halyk**: ожидание — понятная ошибка, в базе ничего не меняется. Тест — задача 7.
5. **Два одинаковых кофе по 1 500 в один день + SMS по одному из них**: ожидание — SMS присоединяется к ближайшему по времени, второй кофе остаётся отдельной записью. Тест — задача 8.
